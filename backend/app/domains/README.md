# Backend Domain Boundaries

These packages reserve clean architecture boundaries from the Phase 1 documentation.

No domain models, use cases, repositories, policies, or orchestration behavior are implemented yet.

Planned domains:

- `identity`: tenants, users, memberships, roles, and service accounts.
- `workspaces`: workspace configuration and scoped collaboration.
- `conversations`: conversations, messages, attachments, citations, and feedback.
- `memory`: long-term memory metadata, provenance, retention, and review.
- `knowledge`: knowledge collections, sources, ingestion jobs, chunks, and retrieval metadata.
- `agents`: agent definitions, runs, steps, approvals, and evaluations.
- `governance`: policies, audit events, retention rules, and compliance exports.
